## 📋 项目简介

本项目是一款面向普通用户的**在线图片编辑工具**，专注于**拼图DIY裁剪**场景。用户上传任意照片后，可自由选择拼图尺寸（35片~300片）、调整图片位置和缩放、叠加精美相框效果、添加自定义文字，最终导出高清拼图效果图。

### 核心特性

- **零安装** — 浏览器打开即用，无需下载任何软件
- **轻量高速** — 纯前端 Canvas 渲染，无后端依赖，首屏加载 < 2s
- **多端适配** — 完美支持手机/平板/PC 各尺寸屏幕
- **隐私安全** — 所有图片仅在本地浏览器处理，不上传任何服务器
- **免费开源** — MIT 许可，可自由使用和修改

## 🏗️ 系统架构

### 分层架构

项目采用严格的**分层模块架构**，核心原则是**图片处理与视图显示完全分离**：

```
用户操作 (鼠标/触摸事件)
       │
       ▼
  App (app.js) ── 状态管理 + 事件调度
       │
       ├── imageProcessor.js  ── 图片处理核心
       │      renderImage() → PuzzleCanvas（已完成裁剪/缩放/旋转/填充）
       │
       ├── frameProcessor.js  ── 相框显示（纯显示，不参与图片处理）
       │      renderFrame() → 在Canvas上叠加透明PNG相框
       │
       ├── textProcessor.js   ── 文字渲染模块
       │      renderTexts() → 在Canvas上绘制文字叠加层（含控制框）
       │
       ├── download.js        ── 下载导出（PC直接下载 / 移动端长按保存）
       │
       └── ColorPicker.js     ── HSV颜色选择器组件
```

### 渲染流程

```
scheduleRender()
  → requestAnimationFrame()
    → rebuildPuzzle()        // 生成 PuzzleCanvas（拼图）
    → refreshDisplay()       // 叠加相框 + 叠加文字
      → renderFrame()        // 相框渲染（如有）
      → renderTexts()        // 文字渲染（基于拼图尺寸覆盖层）
```

**关键设计决策：**
- 文字坐标基于**拼图尺寸**（而非屏幕尺寸），确保相框/无框/下载三模式位置一致
- 最终下载图中相框不参与、文字参与（文字属于编辑内容）
- 所有渲染在 Canvas 上完成，不依赖 DOM 元素

## 🚀 快速开始

### 环境要求

- Node.js >= 18
- npm >= 9

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/shuren188/puzzle-frame-effect.git
cd puzzle-frame-effect

# 安装依赖
npm install

# 启动开发服务器（默认端口 3000）
npm run dev

# 构建生产版本
npm run build

# 部署到 GitHub Pages
npm run deploy
```

## 📖 使用指南（详细）

### 1️⃣ 上传图片

- **方式一：点击上传** — 点击页面中央的上传区域，从文件选择器中选择图片
- **方式二：拖拽上传** — 直接从文件夹拖拽图片到上传区域
- 支持的格式：JPEG / PNG / WebP / TIFF / BMP / GIF / SVG / AVIF

### 2️⃣ 选择拼图尺寸

- 底部工具栏默认选中「拼图尺寸」
- 5种尺寸可选：35片(10×15cm) / 70片(15×20cm) / 120片(20×25cm) / 200片(21×30cm) / 300/520片(26×38cm)
- 切换尺寸后画布自动重新适配

### 3️⃣ 调整图片

- **缩放**：在「旋转角度」面板拖动滑块（50%~300%），或直接在预览区双指捏合
- **旋转**：点击左转90° / 右转90° 按钮
- **拖动**：在画布上直接拖拽图片调整裁剪位置
- **重置**：点击顶栏「重置」按钮恢复默认状态

### 4️⃣ 设置填充颜色

- 在「填充颜色」面板选择预设颜色（白/黑/蓝/紫/粉）
- 点击 `+` 按钮打开HSV颜色选择器自定义任意颜色

### 5️⃣ 添加相框（可选）

- 点击预览区右上角的「添加相框」开关
- 系统自动根据当前拼图尺寸和旋转方向匹配横版/竖版相框
- 文字会自动跟随拼图缩放至相框内框区域
- 再次点击开关关闭相框预览

### 6️⃣ 添加和编辑文字

**创建文字：**
1. 点击底部工具栏「添加文字」按钮
2. 画布中央出现「点击输入文字」文字框，自动弹出输入弹窗
3. 输入文字内容，点击 ✓ 确认（或点击 ✕ 取消）

**编辑已有文字：**
- 点击画布上的文字主体 → 弹出输入弹窗修改内容

**修改颜色：**
- 在底部面板或输入弹窗中点击颜色按钮即时切换
- 点击 `+` 按钮打开HSV颜色选择器

**移动位置：**
- 单指/鼠标直接拖拽文字框
- 拖动过程流畅，基于增量式跟踪，手指离开画布边界不影响

**缩放大小：**
- 双指捏合缩放文字
- 或拖拽右下角 ↻ 角控件同时旋转+缩放

**角控件操作：**
| 位置 | 图标 | 功能 |
|------|------|------|
| 左上角 | `⋯` | 弹出图层上移/下移菜单 |
| 右上角 | `✕` | 直接删除该文字 |
| 左下角 | `+1` | 复制一层相同文字 |
| 右下角 | `↻` | 拖拽旋转角度+缩放大小 |

**图层管理：**
- 点击文字左上角 `⋯` 或底部面板的 ↑/↓ 按钮
- 上移一层 / 下移一层调整前后顺序

### 7️⃣ 下载图片

- 点击顶栏「下载图片」按钮
- **PC端**：直接下载 PNG 文件
- **手机端**：弹窗展示高清图片 → 长按图片保存到相册
- 下载内容：拼图 + 文字（不包含相框）
