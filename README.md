# 🧩 拼图裁剪相框效果图

> 在线拼图DIY裁剪工具 — 上传照片，自由拼图裁剪、添加相框、编辑文字，一键下载高清效果图。

**🌐 在线体验：** [https://shuren188.github.io/puzzle-frame-effect/](https://shuren188.github.io/puzzle-frame-effect/)

## ✨ 功能特性

|------|------|

| 填充颜色 | 纯白、黑色、科技蓝、霓虹紫、樱花粉 + 自定义HSV颜色选择器 |

### 🖼️ 相框效果
| 功能 | 说明 |
|------|------|
| 透明PNG相框 | 10组相框（5种尺寸 × 横版/竖版），每个相框精确匹配内框坐标 |
| 一键开关 | 顶部开关一键开启/关闭相框预览 |
| 背景预加载 | 所有相框在后台预加载，切换流畅 |

### ✏️ 文字编辑（美图秀秀风格）

### 技术栈

- **框架：** 原生 JavaScript (ES Module)
- **构建工具：** Vite 6
- **部署：** GitHub Pages (gh-pages)
- **图形渲染：** Canvas 2D API
- **样式：** 原生 CSS（液态玻璃设计系统）
- **字体：** 系统默认字体（PingFang SC / Microsoft YaHei）
- **依赖：** 零生产依赖，仅开发依赖 Vite + gh-pages

## 📖 使用指南

### 1. 上传图片
点击上传区域或拖拽图片到页面，支持常见的图片格式。

### 2. 选择拼图尺寸
在底部工具栏点击「拼图尺寸」，选择 35片–300片 五种尺寸。

### 3. 调整图片
- 使用「缩放比例」滑块调整图片大小
- 用「旋转角度」按钮左转/右转 90°
- 在预览区直接拖拽/双指缩放图片

### 4. 添加相框（可选）
点击右上角的「添加相框」开关，自动为拼图匹配相框（横版/竖版智能适配）。

### 5. 添加文字（美图秀秀风格）
- 点击底部工具栏「添加文字」按钮
- 画布中央出现文字框：「点击输入文字」
- **自动弹出输入弹窗**，背景虚化
- 在输入框中输入文字，点击 ✓ 确认
- **点击颜色按钮**即时切换文字颜色
- 点击「+」按钮可拾取自定义颜色
- **编辑已有文字：** 点击画布上的文字主体重新打开输入弹窗
- **拖动：** 单指拖拽文字框任意移动位置
- **缩放：** 双指捏合缩放文字大小
- **旋转：** 拖拽右下角 ↻ 图标旋转文字
- **复制：** 点击左下角 +1 图标快速复制
- **删除：** 点击右上角 ✕ 图标直接删除
- **图层：** 点击左上角 ⋮ 图标弹出上移/下移菜单

### 6. 下载图片
点击顶栏的「下载图片」按钮，一键导出高清拼图效果图（含文字）。
