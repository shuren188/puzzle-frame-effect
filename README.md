### 技术栈

- **框架：** 原生 JavaScript (ES Module)
- **构建工具：** Vite 6
- **部署：** GitHub Pages (gh-pages)
- **图形渲染：** Canvas 2D API
- **样式：** 原生 CSS（液态玻璃设计系统）
- **字体：** 系统默认字体（PingFang SC / Microsoft YaHei）
- **依赖：** 零生产依赖，仅开发依赖 Vite + gh-pages

## 📖 使用指南

### 1. 上传图片
点击上传区域或拖拽图片到页面，支持常见的图片格式。

### 2. 选择拼图尺寸
在底部工具栏点击「拼图尺寸」，选择 35片–300片 五种尺寸。

### 3. 调整图片
- 使用「缩放比例」滑块调整图片大小
- 用「旋转角度」按钮左转/右转 90°
- 在预览区直接拖拽/双指缩放图片

### 4. 添加相框（可选）
点击右上角的「添加相框」开关，自动为拼图匹配相框（横版/竖版智能适配）。

### 5. 添加文字
- 点击底部「添加文字」工具
- 输入文字内容，选择颜色
- 点击「添加文字」按钮，文字出现在画布中央
- **拖动：** 点击文字直接拖动到目标位置
- **缩放：** 双指捏合缩放文字大小
- **编辑：** 点击画布上的文字或列表中的文字项，在面板修改内容
- **颜色：** 点击颜色按钮立即更新选中文字的颜色
- **删除：** 选中文字后点击「删除」按钮

### 6. 下载图片
点击顶栏的「下载图片」按钮，一键导出高清拼图效果图（含文字）。
